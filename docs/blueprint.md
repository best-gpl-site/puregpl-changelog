# **App Name**: ChangeHub

## Core Features:

- Data Fetching: Fetches daily changelog data from the provided API: https://apis.puregpl.com/api/v1/script/changelog?raw=true.
- Changelog Display: Displays the fetched changelog entries in a chronological order.
- Filtering: Implements a filtering mechanism to search for specific products or updates within the changelog.
- Navigation: Provides a user-friendly interface to easily navigate through daily updates.

## Style Guidelines:

- Primary color: Indigo (#4B0082) to reflect the depth and organization of the information presented. It conveys knowledge, wisdom, and stability.
- Background color: Very light lavender (#F5EEF8), providing a soft contrast that is easy on the eyes for long reading sessions.
- Accent color: Teal (#008080) for interactive elements like filter buttons and links, offering a fresh and noticeable contrast to guide the user's interaction.
- Clean, sans-serif font optimized for readability on screens.
- Simple, outline-style icons to represent different categories of updates.
- Clear, well-organized layout with a focus on readability and easy navigation.
